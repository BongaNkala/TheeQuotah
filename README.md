# Thee Landlord Cloud — Quotation Studio

Single-file quotation builder for Thee Landlord (Pty) Ltd.

## Files
- `index.html` — the entire app
- `logo.png`   — company logo (auto-loaded from same folder)

## Usage
Open `index.html` in a browser. No build step.

## Deploy
Drop the folder on GitHub Pages, Netlify, Vercel or Cloudflare Pages.
